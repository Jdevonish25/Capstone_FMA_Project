# Software Artefacts

This folder contains PDF exports of the capstone notebooks with code and saved outputs.

## Folders

- `notebook_pdfs/`: PDF exports for all notebook artefacts.
- `notebook_html/`: intermediate HTML exports used to create the PDFs.
- `executed_notebooks/`: executed artefact copies for Notebook 49 and Notebook 50, which did not have embedded outputs in the original `.ipynb` files.
- `logs/`: nbconvert and PDF-rendering logs.

## Manifest

`notebook_pdf_manifest.csv` lists each notebook, the source file used for export, the PDF path, and output counts.
